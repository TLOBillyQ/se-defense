# 02 经济与矿点

## 职责

资金、矿点剩余量、采集与停采、采集速率、矿点离场。

## 依赖

- 电网：矿点是否通电（收电圈 0.5，供电圈 0）。
- 敌人与波次：当前是否处于进攻期。
- 放置：扣费由放置系统触发，本系统只保证资金是唯一账本。

## 规则

- R1 矿点固定不可建造，每个剩余量 300，无血量、不受伤害、不可被维修。
- R2 采集条件：矿点**自身通电** 且 **当前不在进攻期**。两者缺一即停。
- R3 采集节奏：满足条件时每 0.8 秒剩余量 −1、资金 +1（即每矿点 1.25/s）。
- R4 停采：进攻期开始瞬间全图停采；本波全灭后恢复。
- R5 采空：剩余量到 0 时矿点离场（不再占地、不再计入剩余矿点数、不再挡放置）。
- R6 采集速率 = 当前正在采集的矿点数 × 1.25/s。
- R7 资金只增于采集，只减于放置。无退款、无击杀奖励。
- R8 矿点通电只要求接入电网，不要求"在 Core 圈内"；经 Relay 链到达同样有效。

## 必须覆盖的场景

1. 通电矿点、非进攻期：推进 0.8 秒资金 +1、剩余量 −1；推进 8 秒 +10。
2. 未通电矿点：推进任意时间资金不变。
3. 通电矿点在进攻期：资金不变；本波全灭后恢复采集。
4. 剩余量为 1 的矿点再采一次即离场，剩余矿点数 −1。
5. 两个通电矿点采集速率为 2.5/s。
6. 通过 Relay 供电的矿点可采集。
7. Relay 被毁导致矿点断电后停采。

## 不做

- 资源种类、仓库上限、出售。
