# 05 侦测与火力

## 职责

Radar 揭示敌人、Turret 选目标与开火、对敌人造成伤害。

## 依赖

- 电网：Radar/Turret 是否通电。
- 敌人：敌人位置、足迹半径、血量。

## 规则

- R1 揭示：敌人的足迹圆与任一**通电** Radar 的探测圈（8）相交 ⇒ 该敌人处于"已揭示"。离开所有探测圈即不再揭示。
- R2 Turret 只对已揭示、且足迹圆与自身射程圈（5）相交的敌人开火。
- R3 目标选择：射程内已揭示敌人中**最近**者。当前目标失去揭示/离开射程/死亡后重选。
- R4 转向：Turret 以 180°/s 转向目标；枪口与目标夹角 ≤ 2° 才开火。
- R5 开火：每次伤害 0.5，射速 2 次/秒（即 1 DPS）；每次开火先有 0.05 秒光束后结算伤害。
- R6 未通电 Turret 不开火；未通电 Radar 不揭示。
- R7 敌人血量 ≤ 0 即死亡。
- R8 无目标时 Turret 待机（表现层：随机转向），不影响规则。

## 数值

| 项 | 值 |
|---|---|
| Radar 探测圈 | 8 |
| Turret 射程圈 | 5 |
| 伤害 | 0.5 |
| 射速 | 2/s |
| 转速 | 180°/s |
| 开火夹角 | ≤ 2° |

## 必须覆盖的场景

1. 通电 Radar 圈内的敌人已揭示；圈外未揭示。
2. 敌人在 Turret 射程内但无 Radar 覆盖：不受伤害。
3. 敌人已揭示且在射程内，Turret 已朝向目标：1 型敌人（4 血）约 4 秒死亡（8 次 × 0.5）。
4. 两个已揭示敌人，Turret 打更近的。
5. Radar 断电后 Turret 停火；恢复后继续。
6. Turret 断电不开火。
7. 敌人离开射程后停火。
8. 转向：目标在正后方，至少 1 秒后才开第一枪（180° / 180°/s）。

## 不做

- 弹道、命中率、穿透、目标优先级切换选项。
