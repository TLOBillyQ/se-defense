# 03 电网

## 职责

供电圈/收电圈判定、以 Core 为根的供电树、通电状态、断电传播、供电者抢占。

## 依赖

- 建筑血量/离场：节点离场即退出电网。

## 规则

- R1 节点：Core、Relay、Radar、Turret、Repair、矿点都是节点。只有 Core 与 Relay 有供电圈（4 / 3）；其余供电圈为 0，是叶节点。
- R2 接入：节点的收电圈与某供电者的供电圈相交（圆心距 ≤ 供电圈 + 收电圈）即可接入该供电者。
- R3 供电前提：供电者只有**自身通电**时才对外供电。Core 恒通电。
- R4 通电定义：存在一条 节点 → Relay → … → Core 的接入链。
- R5 树：每个节点同一时刻只有一个供电者。
- R6 抢占：已接入的节点，仅当出现**更近**（圆心距更小）的通电供电者、且该供电者不是本节点的下游时，才换到新供电者。
- R7 断电传播：供电者失电、离场或不再相交时，下游整条分支断电。摧毁一个 Relay 会让其下游所有 Relay/建筑/矿点断电。
- R8 去抖：通电/断电变化需持续 0.15 秒才生效。
- R9 未通电建筑：不侦测、不开火、不维修、不产钱；但仍占地、仍有血量、仍可被炸。
- R10 未通电的 Relay 不对外供电，因此放在电网外的 Relay 既不通电也不能给别人供电。

## 数值

| 节点 | 供电圈 | 收电圈 |
|---|---|---|
| Core | 4 | 0.1 |
| Relay | 3 | 0.1 |
| Radar / Turret / Repair | 0 | 0.1 |
| 矿点 | 0 | 0.5 |

判定示例：Relay 圆心距 Core ≤ 4.1 即接入；Radar 距某通电 Relay ≤ 3.1 即接入；矿点距 Relay ≤ 3.5 即接入。

## 必须覆盖的场景

1. Core 圈内的 Relay 通电；圈外 0.2 的 Relay 不通电。
2. Relay 链：Core → Relay A (0, 3.5) → Relay B (0, 7) → Radar (0, 10)，Radar 通电。
3. 摧毁 Relay A 后 Relay B 与 Radar 同时断电（0.15 秒后）。
4. 补回 Relay A 后恢复通电。
5. 边界值：圆心距恰好等于半径和时通电。
6. 抢占：节点先接入远供电者，更近供电者出现后切换；更远的不切换。
7. 环保护：下游 Relay 更近也不能成为上游的供电者。
8. 未通电 Relay 圈内的建筑不通电。
9. 未通电建筑仍受炸弹伤害。

## 不做

- 电量、负载、电池。
