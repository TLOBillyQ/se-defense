# 04 放置

## 职责

选择要建的建筑、合法落点判定、确认/取消、扣费。

## 依赖

- 经济：当前资金。
- 电网：通电供电圈集合。
- 世界：现有足迹圆集合（建筑 + 未采空矿点）。
- 对局流程：仅 Playing 可放置。

## 规则

- R1 可建建筑：Relay 10、Radar 50、Turret 50、Repair 100。Core 与矿点不可建造。
- R2 可负担：资金 < 价格的建筑不可选择进入放置态。
- R3 放置态：同一时刻最多一个待建类型。选择另一类型前须先取消。
- R4 合法落点（同时满足）：
  - 以落点为圆心、该建筑足迹半径为半径的圆**不与任何已有足迹圆相交**（建筑与未采空矿点）；
  - 落点（半径 0 的点）**位于某个通电供电者的供电圈内**（Core 或通电 Relay）。
- R5 确认：在合法落点确认 → 建筑出现在该点、资金 −价格、退出放置态。
- R6 非法落点确认无效，仍处于放置态。
- R7 取消：退出放置态，不扣费。
- R8 落点必须在棋盘范围内。
- R9 新放置的建筑立即加入电网判定（0.15 秒去抖后通电）。
- R10 不存在选中、移动、拆除、退款。

## 必须覆盖的场景

1. 资金 100 时可选 Relay/Radar/Turret/Repair；资金 99 时 Repair 不可选。
2. 放 Relay 于 (0, 3) 成功，资金 100 → 90，Relay 数量 1。
3. 每种建筑各放一次，扣费等于价格（场景大纲）。
4. 足迹重叠：Turret 落在 (0.9, 0) 与 Core 足迹相切（0.4 + 0.5），相切算相交，不能放；(0.91, 0) 可以放。
5. 落点在 Core 圈外（(0, 4.01)）不能放；(0, 4) 可以放。
6. 落点只在未通电 Relay 圈内不能放。
7. 落点在矿点足迹上不能放；矿点采空离场后可以放。
8. 非法落点确认后仍处于放置态且资金不变；取消后不处于放置态。
9. 放置态中确认后资金不足以再放同类型时，该类型不可再选。

## 不做

- 拆除、移动、批量放置、网格吸附。
