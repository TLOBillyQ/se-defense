# 13 覆盖圈与链路

## 规则

- O1 默认（无悬停、无放置）：显示整棵供电树的链路（每个已接入节点到其供电者的线段）。
- O2 悬停某单位：显示该单位类型的**全图同类覆盖圈**（Power/Radar/Turret/Repair），该单位到 Core 的供电链，以及 1.5 倍足迹的高亮环；不显示整棵树。
- O3 放置态：显示全图通电供电圈；若待建类型不是 Relay，再叠加该类型的全图覆盖圈；足迹预览圆随落点移动，合法绿/非法红。
- O4 未通电建筑不注册功能覆盖圈（不在 Radar/Turret/Repair 覆盖圈显示中），但 Core/Relay 的供电圈始终按其通电状态显示（只显示通电供电者）。
- O5 覆盖圈按类型着色；多圆显示为并集轮廓。
- O6 只在 Playing 显示。

## 必须覆盖的场景

1. 一个 Relay 接入 Core：默认显示 1 条链路线。
2. 悬停 Turret：显示所有 Turret 射程圈 + 该 Turret 到 Core 的链 + 高亮环。
3. 放置 Turret：显示通电供电圈 + 所有 Turret 射程圈 + 预览圆；未通电 Relay 的供电圈不显示。
4. 预览圆在合法落点为绿、非法为红。
