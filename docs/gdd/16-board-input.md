# 16 棋盘输入（照目的地）

## 规则

- I1 视角：固定俯视棋盘，不可平移、缩放、旋转。
- I2 触摸/点击落到棋盘平面得到落点；落点在棋盘外无效。
- I3 非放置态：点击单位 = 悬停该单位（显示描述与覆盖）；点击空地 = 清除悬停。
- I4 放置态：拖动/移动更新预览落点；在合法落点点击 = 确认；点击当前类型的建造按钮 = 取消。
- I5 建造按钮点击进入放置态（Unity 热键 E/R/T/Y 与 Escape 在目的地无对应，不实现）。
- I6 消息行文案改为 `Placing <建筑名> — tap its button to cancel`。
- I7 结束面板"重开"按钮触发重开；Pregame"开始"按钮触发开始对局。
- I8 仅 Playing 接受棋盘输入；面板按钮按各阶段可用。

## 必须覆盖的场景

1. 点击 Relay 按钮进入放置态；点击 (0, 3) 放置成功。
2. 放置态再点 Relay 按钮取消。
3. 棋盘外点击无效。
4. 非放置态点击 Core 产生悬停。
5. Pregame 点击棋盘无效；点击开始后进入 Playing。
