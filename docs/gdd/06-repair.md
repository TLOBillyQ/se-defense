# 06 维修

## 职责

Repair 选目标并恢复建筑血量。

## 依赖

- 电网：Repair 是否通电。
- 建筑血量。

## 规则

- R1 通电 Repair 在维修圈（5）内选择**血量比例最低且 < 1** 的建筑作为目标，一次只修一个。
- R2 排除自己；Repair 之间可互修。
- R3 维修速率 0.5 血/秒，不超过上限。
- R4 目标修满、离开维修圈或离场后重选。
- R5 矿点没有血量，不是维修目标。
- R6 未通电 Repair 不维修。
- R7 判定范围：目标足迹圆与维修圈相交。

## 必须覆盖的场景

1. 圈内 Turret 3/5 血，推进 4 秒后满血。
2. 两个受伤建筑：Relay 1/2（50%）与 Turret 3/5（60%），先修 Relay；Relay 修满后转修 Turret。
3. Repair 自身受伤且圈内无其他伤员：不自修。
4. 两座 Repair 互修。
5. 断电 Repair 不维修。
6. 圈外受伤建筑不被修。

## 不做

- 维修费用、优先级设置。
